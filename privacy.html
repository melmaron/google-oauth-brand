プライバシーポリシー

Hermes Calendar（個人用ツール）／ 最終更新: 2026年11月5日

本ポリシーは、個人が自分専用に運用しているデスクトップアプリケーション 「Hermes Calendar」（以下「本アプリ」）における Google ユーザーデータの取り扱いを定めるものです。 本アプリは作者本人のみが利用し、一般の利用者に提供していません。

1. 取得する情報

本アプリは、作者本人が明示的に許可した範囲でのみ、以下の情報にアクセスします。

対象アクセス内容用途
Google カレンダー 予定の読み取り（「授業」カレンダーおよび予定の一覧） 授業の開始前の通知、課題の検出
Google ToDo（Tasks） タスクの作成・参照 検出した課題を ToDo として登録
Google ドライブ / スプレッドシート / ドキュメント 読み取りおよび作成・編集 本人が明示的に依頼した作業のみ
Gmail 読み取りのみ（送信・削除・変更は行いません） 本人が依頼した検索・要約のみ

2. 利用目的

取得した情報は、作者本人の授業スケジュール管理、課題のリマインド、および 本人が依頼した文書作成・調査のためにのみ使用します。これ以外の目的では使用しません。

3. 保存と処理の場所

本アプリは作者本人のパソコン上で動作します。Google API との通信は端末から直接行われ、 データを第三者のサーバーへ送信・保存することはありません。 OAuth の認証情報（リフレッシュトークン）は端末内の設定ディレクトリに、 本人のみが読み取れる権限（0600）で保存されます。

4. 第三者への提供

取得した Google ユーザーデータを、販売・貸与・共有・広告目的で第三者に提供することはありません。 Google ユーザーデータを、広告配信や信用調査のために利用することもありません。

5. 人による閲覧

本アプリの利用者は作者本人のみであるため、取得したデータを読むのは本人だけです。 作者以外の第三者がその内容を閲覧することはありません。

6. 保存期間と削除

本アプリは Google 上のデータの複製を恒久的に保存しません。取得した内容は処理のために 一時的にメモリ上で扱うのみです。端末内に保存された認証情報は、 Google アカウントの「サードパーティ製アプリ」 からアクセス権を取り消すことで無効化できます。

7. Google API Services User Data Policy への準拠

本アプリによる Google API から取得した情報の使用および転送は、 Google API Services User Data Policy （Limited Use 要件を含む）に準拠します。

8. 変更

本ポリシーを変更する場合は、このページを更新します。重要な変更がある場合は 最終更新日を改定します。

9. お問い合わせ

本ポリシーに関するお問い合わせは GitHub のプロフィール からお願いします。
